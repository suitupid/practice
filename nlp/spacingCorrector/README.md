# 띄어쓰기 교정 서비스
한국어 문장을 입력받아 띄어쓰기를 문법에 맞게 교정하는 서비스
### 기능
* 웹페이지
  - 한국어 문장 입력하고 띄어쓰기 교정 결과를 보여주는 페이지
  - 입력 및 출력 문장 지우기 버튼
  - 문자열을 웹서버로 전송하는 버튼
  - 웹서버에서 응답한 교정 결과를 표시
  - 사용 기술: html, css, javascript
* 웹서버
  - 문자열을 받아 추론을 위해 추론 API로 판별 요청
  - 추론 API 응답을 받아 웹페이지로 전달
  - 사용 기술: nodejs
* 추론 API
  - 입력된 문장의 공백을 제거
  - 학습 모델에 공백 제거된 문장을 입력하여 결과 추론
  - 추론 결과를 웹서버로 전달
  - 사용 기술: fastapi
* 학습 모델 구축 
  - 문어체 및 구어체 문장을 고루 학습하기 위해 신문 기사 및 대화 문장 활용
  - 문자열의 글자마다 다음에 띄어쓰기가 있는지 TF로 구분
  - 토큰은 글자 단위로 정의
  - Transformer 레이어 구성
  - 클래스 간 weight 설정 
  - 사용 기술: pytorch(lightning)
